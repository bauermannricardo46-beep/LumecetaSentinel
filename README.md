# Lumeceta Sentinel

Android-first investment intelligence dashboard.

## Current direction
- Trading 212 read-only integration
- Portfolio, account cash, P/L and positions
- Native Android API layer
- Premium dark/purple UI

## Security
Never commit Trading 212 API keys or secrets. Use local device storage / environment secrets only.

## Build
Open the project in Android Studio on the development PC and build the debug APK.
